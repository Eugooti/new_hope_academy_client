When using the `jspdf` package to create PDFs, there are a variety of styles and document formatting options available
to you. These include page layouts, fonts, colors, margins, and more. Below is an overview of common styles and
formatting techniques you can apply in your PDFs:

### 1. **Page Layout and Margins**

- **Page Size & Orientation:**
  You can create documents in different sizes like `A4`, `letter`, and others, as well as set the page orientation to
  `portrait` or `landscape`.

  ```javascript
  const doc = new jsPDF({
      orientation: 'landscape',  // or 'portrait'
      unit: 'mm',               // units: 'mm', 'pt', 'cm', 'in'
      format: 'a4'              // paper format: 'a4', 'letter', etc.
  });
  ```

- **Custom Margins:**
  You can manually set custom margins or padding within the document.

  ```javascript
  doc.setMargins({
      top: 20,
      bottom: 20,
      left: 15,
      right: 15
  });
  ```

### 2. **Fonts and Text Styling**

- **Font Families and Sizes:**
  `jspdf` comes with built-in font families such as `times`, `courier`, and `helvetica`. You can change the font style
  (bold, italic) and size dynamically.

  ```javascript
  doc.setFont('helvetica', 'bold'); // Set font family and style
  doc.setFontSize(16); // Set font size
  doc.text("Hello World", 10, 10); // Add text at coordinates (x, y)
  ```

- **Custom Fonts:**
  You can embed custom fonts using TTF (TrueType) or OTF (OpenType) fonts in `jspdf`. This allows you to maintain
  brand consistency or specific design requirements.

  ```javascript
  doc.addFileToVFS("CustomFont.ttf", fontBase64);
  doc.addFont("CustomFont.ttf", "CustomFont", "normal");
  doc.setFont("CustomFont"); // Use the custom font
  ```

- **Font Color:**
  You can change the color of the text dynamically.

  ```javascript
  doc.setTextColor(0, 102, 204); // RGB color for blue
  doc.text("Colored Text", 10, 20);
  ```

### 3. **Document Structure (Headers and Footers)**

- **Headers:**
  You can create headers that repeat on every page by using the `doc.text()` method inside a loop that checks
  the current page number.

  ```javascript
  const pageCount = doc.getNumberOfPages();
  for (let i = 1; i <= pageCount; i++) {
      doc.setPage(i);
      doc.text(`New Hope Academy Payroll`, 10, 10); // Add to the top of each page
  }
  ```

- **Footers:**
  Similarly, footers can be added to the bottom of each page.

  ```javascript
  doc.text(`Page ${i} of ${pageCount}`, 180, 290); // For A4 size page
  ```

### 4. **Tables (Using `jspdf-autotable`)**

You can use the `jspdf-autotable` plugin to add tables with styling.

- **Table Styling:**
  The `jspdf-autotable` library offers advanced table styling, such as custom colors, fonts, and alignment.
  You can define column headers, row data, and table styles.

  ```javascript
  doc.autoTable({
      head: [['Column 1', 'Column 2', 'Column 3']],
      body: [
          ['Data 1', 'Data 2', 'Data 3'],
          ['Data A', 'Data B', 'Data C']
      ],
      theme: 'striped', // 'grid', 'plain', 'striped'
      styles: {
          fontSize: 10,
          cellPadding: 4,
          textColor: [0, 0, 0]
      },
      headStyles: {
          fillColor: [22, 160, 133] // Custom header color
      },
      alternateRowStyles: {
          fillColor: [240, 240, 240] // Alternating row color
      }
  });
  ```

### 5. **Shapes and Images**

- **Add Shapes (Rectangles, Circles, Lines):**
  You can add various shapes like rectangles, circles, or lines.

  ```javascript
  doc.setDrawColor(0, 0, 255); // Blue outline
  doc.setFillColor(0, 255, 0); // Green fill
  doc.rect(20, 20, 50, 50, 'FD'); // Draw a filled rectangle with border
  ```

- **Add Images:**
  You can embed images (JPEG, PNG) into the PDF using base64 strings or file paths.

  ```javascript
  const imgData = 'data:image/jpeg;base64,...'; // Base64 image data
  doc.addImage(imgData, 'JPEG', 10, 10, 50, 50); // (image, format, x, y, width, height)
  ```

### 6. **Line and Paragraph Spacing**

- **Line Height:**
  You can control line spacing by using `doc.text` and specifying a Y-offset manually for each line.

  ```javascript
  doc.setFontSize(12);
  doc.text("First Line", 10, 20);
  doc.text("Second Line", 10, 30); // Adds a line height of 10 units
  ```

- **Multi-line Text:**
  To add multi-line text, use an array for `doc.text()`.

  ```javascript
  doc.text(["This is line one.", "This is line two."], 10, 20);
  ```

### 7. **Page Numbering**

You can dynamically add page numbers using the `getNumberOfPages()` method to iterate over each page.

```javascript
const pageCount = doc.getNumberOfPages();
for (let i = 1; i <= pageCount; i++) {
    doc.setPage(i);
    doc.text(`Page ${i} of ${pageCount}`, 180, 290);
}
```

### 8. **Document Metadata**

You can set document metadata like title, subject, and author.

```javascript
doc.setProperties({
  title: 'Payroll Report',
  subject: 'Employee Salary Details',
  author: 'New Hope Academy',
});
```

### 9. **Multiple Pages**

To add multiple pages, you can use the `doc.addPage()` method.

```javascript
doc.text("First Page Content", 10, 20);
doc.addPage();
doc.text("Second Page Content", 10, 20);
```

### 10. **Customizing Styles Based on Themes**

You can apply dynamic themes and styles to the document based on user preferences (e.g., dark or light mode) by
adjusting text color, fill color, and font properties.

To style specific sections of your document when using `jspdf`, such as making a heading bold and underlined while
keeping the body text normal, you can use different font styles and formatting methods for each section. Here’s
how to achieve that:

### 1. **Bold and Underlined Heading**

To create a bold and underlined heading, you can use the following steps:

- **Bold Font:** Use `doc.setFont('fontFamily', 'bold')` for bold text.
- **Underline:** Unfortunately, `jspdf` doesn’t have built-in underline support, but you can simulate it by drawing a line under the text.

Here’s an example:

```javascript
const doc = new jsPDF();

doc.setFont('helvetica', 'bold'); // Set font to bold
doc.setFontSize(16); // Set a larger font size for the heading
doc.text("This is a Heading", 10, 20); // Add heading text

// Add underline by drawing a line under the text
doc.line(10, 22, 60, 22); // x1, y1, x2, y2 (positions for the line)

// Reset font for the body text
doc.setFont('helvetica', 'normal'); // Set font to normal
doc.setFontSize(12); // Set font size for the body
doc.text("This is body text that is not bold and has no underline.", 10, 30);
```

### 2. **Available Font Types in jsPDF**

The default fonts that come with `jspdf` are:

- **Helvetica** (Sans-serif)
- **Times** (Serif)
- **Courier** (Monospace)

For each of these fonts, you can set the following styles:

- `normal`
- `bold`
- `italic`
- `bolditalic`

Here’s how to switch between fonts:

```javascript
// Helvetica font (default)
doc.setFont('helvetica', 'normal'); // Normal Helvetica
doc.setFont('helvetica', 'bold'); // Bold Helvetica
doc.setFont('helvetica', 'italic'); // Italic Helvetica
doc.setFont('helvetica', 'bolditalic'); // Bold Italic Helvetica

// Times font (serif)
doc.setFont('times', 'normal'); // Normal Times
doc.setFont('times', 'bold'); // Bold Times
doc.setFont('times', 'italic'); // Italic Times
doc.setFont('times', 'bolditalic'); // Bold Italic Times

// Courier font (monospace)
doc.setFont('courier', 'normal'); // Normal Courier
doc.setFont('courier', 'bold'); // Bold Courier
doc.setFont('courier', 'italic'); // Italic Courier
doc.setFont('courier', 'bolditalic'); // Bold Italic Courier
```

### 3. **Using Custom Fonts**
If the default fonts are not enough for your needs, you can add custom fonts (TTF or OTF) to `jspdf` using the
`addFileToVFS` method. You need the font file in base64 format.

```javascript
doc.addFileToVFS("CustomFont.ttf", fontBase64);
doc.addFont("CustomFont.ttf", "CustomFont", "normal");
doc.setFont("CustomFont");
doc.text("This is custom font text", 10, 40);
```

### 4. **Text Colors and Line Styling**

You can also customize colors and line styles for specific sections:

```javascript
// Heading text in bold and blue
doc.setTextColor(0, 0, 255); // Set text color to blue
doc.setFont('helvetica', 'bold');
doc.text("Colored Heading", 10, 50);

// Reset color for body text
doc.setTextColor(0, 0, 0); // Set text color back to black
doc.setFont('helvetica', 'normal');
doc.text("Normal body text here.", 10, 60);

// Add another underline
doc.setDrawColor(255, 0, 0); // Red line
doc.line(10, 62, 80, 62); // Red underline
```

- Change text colors with `doc.setTextColor()` to enhance specific sections.

By applying these combinations of styles, you can format headings, sections, and body text in any way you like.
